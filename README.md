# Food Price Intelligence System (Nigeria)
[![DOI](https://zenodo.org/badge/1452971345.svg)](https://doi.org/10.5281/zenodo.24116876)

Streamlit app that combines long-term WFP food price data with short-term NBS Selected Food price reports to show trends, forecasts and data-source details.

## Run locally

pip install -r requirements.txt
streamlit run app.py

## Data

Data files are not included in this repository.
- WFP: download the Nigeria food prices CSV from the WFP/HDX website and place it in the `data/` folder.
- NBS: download the Selected Food Price Watch Excel files from the NBS website and place them in `data/`.
